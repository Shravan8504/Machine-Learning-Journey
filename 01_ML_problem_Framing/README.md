## Learning Outcome

In this example, we learned how to frame a machine learning problem by identifying:

- Problem Statement
- Features
- Target Variable
- Machine Learning Type
- Problem Type
- Evaluation Metric

## Example Output

The program identifies this as a binary classification problem.

### Features
- Attendance
- Study Hours
- Previous Marks
- Assignment Score

### Target
- Pass or Fail

### Evaluation Metric
- Accuracy

## What I Learned

- How to define a machine learning problem
- How to identify features and target variables
- Difference between classification and regression
- How to choose an evaluation metric

## Problem Framing Checklist

1. Define the problem clearly
2. Identify the input features
3. Define the target variable
4. Choose the ML problem type
5. Select an evaluation metric
